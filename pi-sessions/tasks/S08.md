## Frozen prompt (submit to Pi)

The Bash script below is supposed to copy every regular file located directly inside the directory
named by its first argument into the directory named by its second argument, but it is broken.
Repair it so that: filenames with spaces, tabs, leading dashes, or other awkward characters are
handled correctly; only regular files are copied (symlinks are skipped, never followed); the
destination must already exist as an empty directory, otherwise print a diagnostic to stderr and
exit with status 2 before copying anything; the source directory and all its files remain
byte-identical and in place afterwards. Keep the same two-argument interface and the same file
name `solution.sh`. You may rewrite the contents completely as long as the interface and behavior
are as specified.

```bash
#!/bin/bash
for f in $1/*; do
    cp $f "$2"
done
```

## Acceptance checks

- All direct regular files copied byte-identically into the empty destination — including names
  with spaces, leading dashes, tabs, and hidden dotfiles (a bare `*` glob does not match dotfiles,
  so the repaired script must handle them another way).
- Symlinks skipped (not copied); subdirectories not copied.
- Invalid destination → exit 2, nothing written; missing args → exit 2.
- Source byte-identical afterwards.
- Starter-defect regression cases all pass (word-splitting, dash-injection into `cp`).
