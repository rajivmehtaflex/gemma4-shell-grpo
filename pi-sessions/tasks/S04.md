# S04 — CSV file inventory · v1

Lineage: new authored template (development pool; excluded from the final test set).

## Invocation

`solution.sh <directory>`

## Frozen prompt (submit to Pi)

Write a Bash script that lists every regular file whose name ends in `.csv` (case-sensitive)
anywhere under its first argument, one path per entry, printed relative to that argument without a
leading `./`. Separate entries with NUL bytes — not newlines — because relative paths may contain
spaces, tabs, leading dashes, and newline characters. Sort the entries by their relative-path bytes
in C locale order (plain byte sort). Skip symlinks: neither list nor follow them. Do not modify
anything. If the argument is missing, is not a directory, or cannot be read, print a diagnostic to
stderr, write nothing to stdout, and exit with status 2. An empty tree is a success with empty
output.

## Acceptance checks

- Exact expected entry set and byte-exact NUL-delimited output on the fixture (deep nesting,
  awkward names incl. newline, symlinks skipped, non-`.csv` excluded, `.CSV` excluded).
- Sortedness verified byte-wise; no `./` prefix on any entry; last entry NUL-terminated.
- Empty tree → empty stdout, exit 0.
- Invalid/unreadable argument → exit 2, empty stdout, nonempty stderr.
- Input tree byte-identical afterwards.
