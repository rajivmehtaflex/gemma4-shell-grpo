# S01 — Count direct `.txt` files · v1

Lineage: shares a template with D01 (development pool; excluded from the final test set).

## Invocation

`solution.sh <directory>`

## Frozen prompt (submit verbatim to Pi)

Write a Bash script that counts regular files whose names end in `.txt` (lowercase, case-sensitive)
located directly inside the directory given as its first argument. Never descend into
subdirectories and never count symlinks, even symlinks pointing at `.txt` files. Print exactly the
decimal count followed by a single newline. Filenames may contain spaces, leading dashes, tabs, or
newline characters. If the argument is missing, is not a directory, or cannot be read, print a
diagnostic to stderr, write nothing to stdout, exit with status 2, and change nothing on disk.

## Acceptance checks

- Correct count on a fixture containing: simple names, names with spaces, a leading-dash name, a
  name containing a newline; nested `.txt` files (not counted); `.txt` symlinks (not counted);
  `.TXT`/`.Txt` files (not counted); non-`.txt` files.
- Empty directory prints `0`.
- Missing argument → exit 2, nonempty stderr, empty stdout.
- First argument is a regular file (not a directory) → exit 2.
- Unreadable directory → exit 2.
- Directory contents byte-identical before and after.

Fixture spec: `fixtures/S01.md`.
