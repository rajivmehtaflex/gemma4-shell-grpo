# S02 — Copy `.log` files recursively · v1

Lineage: shares a template with D02 (development pool; excluded from the final test set).

## Invocation

`solution.sh <source-dir> <dest-dir>`

## Frozen prompt (submit verbatim to Pi)

Write a Bash script that copies every regular file whose name ends in `.log` (case-sensitive) from
the directory tree under its first argument into its second argument, preserving each file's path
relative to the source directory and preserving file bytes exactly. Skip symlinks: never copy a
symlink entry and never follow directory symlinks while recursing. The destination must already
exist as an empty directory; if it is missing, is not a directory, is not empty, or is located
inside the source directory (or equals it), print a diagnostic to stderr, write nothing anywhere,
and exit with status 2 — all validation before the first write. The source directory must remain
byte-identical afterwards. Filenames may contain spaces and leading dashes.

## Acceptance checks

- All matching files copied with identical relative paths and `cmp`-identical bytes; nested
  duplicate basenames land in their own subdirectories.
- Non-`.log` files and `.LOG` files not copied; symlinks neither copied nor followed.
- Source tree byte-identical afterwards (names, contents, directory structure).
- Invalid destination (missing / not a directory / not empty / inside source / equal to source) →
  exit 2, nothing written anywhere.
- Missing arguments → exit 2.
