## Invocation

`solution.sh <input-file>`

## Frozen prompt (submit to Pi)

Write a script that reads the CSV file given as its first argument and writes a new CSV to stdout
containing only the `id` and `name` columns. The input is valid UTF-8 and its header row is exactly
`id,name,amount`. The output's first line must be the header `id,name`, followed by one row per
input data row in the same order, keeping the `id` and `name` values byte-for-byte. Values may
contain quoted commas, doubled quote characters, and embedded newlines — preserve them correctly
per CSV quoting rules, so that parsing the output yields exactly the original `id` and `name`
values. Use LF line endings. If the file is missing, unreadable, not valid UTF-8, or its header is
not exactly `id,name,amount`, print a diagnostic to stderr, write nothing to stdout, and exit with
status 2. Do not modify the input. Python 3's standard-library `csv` module is available and may
be used.

## Acceptance checks

- Output parses as CSV; every row's `id`/`name` values equal the input's (including values with
  commas, escaped quotes `"…"…""`, and embedded newlines); row count and order preserved; header
  is exactly `id,name`; LF endings.
- Round-trip check performed by an independent parser, not by string equality with a fixed
  expected quoting style.
- Missing/unreadable file, invalid UTF-8, wrong header → exit 2, empty stdout.
- Input byte-identical afterwards.
