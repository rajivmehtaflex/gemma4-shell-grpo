# S03 — Move direct `.bak` files · v1

Lineage: new authored template (development pool; excluded from the final test set).

## Invocation

`solution.sh <source-dir> <archive-dir>`

## Frozen prompt (submit to Pi)

Write a Bash script that moves every regular file whose name ends in `.bak` (case-sensitive) and
that sits **directly inside** its first argument — never inside subdirectories, never symlinks —
into the directory given as its second argument, keeping the original basenames. The archive
directory must already exist, be empty, and lie completely outside the source directory: if it
equals the source, is inside it, or contains the source as a subdirectory, refuse before touching
anything. The same refusal applies when arguments are missing, the directories do not exist, or
the archive is not empty: print a diagnostic to stderr and exit with status 2 without moving or
modifying any file. Files that are not moved — including files in subdirectories and non-`.bak`
files — must remain byte-identical and in place.

## Acceptance checks

- Exactly the direct regular `.bak` files moved; basenames preserved; bytes identical after move.
- Subdirectory `.bak` files and `.bak` symlinks untouched and unmoved.
- All unselected files byte-identical and in place; source contains no leftovers.
- Refusals (archive equal to source, archive inside source, source inside archive, missing/empty
  violations) → exit 2 with zero mutations (verified by full-tree hash before/after).
- Missing arguments → exit 2.
