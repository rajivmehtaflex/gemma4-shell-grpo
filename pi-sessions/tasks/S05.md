# S05 — Aggregate TSV values · v1

Lineage: shares a template with D03 (development pool; excluded from the final test set).

## Invocation

`solution.sh <input-file>`

## Frozen prompt (submit to Pi)

Write a Bash script that reads a headerless two-column TSV file given as its first argument and
prints one `key<TAB>total` line per distinct key, with the totals summed, sorted ascending by key
bytes in C locale order. Keys are nonempty and contain no tab or newline characters; values are
nonnegative decimal integers. The file has at most 1,000 rows and no value exceeds 1,000,000. An
empty input file is a success with no output. If any row is malformed — wrong field count, empty
key, or a value that is not a plain nonnegative integer — print a diagnostic to stderr, write
nothing to stdout, exit with status 2, and leave the input unchanged. A missing or unreadable
input file is also exit 2.

## Acceptance checks

- Correct sums and byte-exact C-locale key order on the main fixture (duplicate keys, keys that
  differ only by case or by digit-vs-letter adjacency to expose numeric-vs-byte sorting).
- Single-row file; keys summing across non-adjacent rows.
- Empty file → empty stdout, exit 0.
- Malformed rows (3 fields; empty key; value `-5`; value `12a`; value `+7`; value `0012` is valid
  and equals 12) → exit 2, empty stdout, nonempty stderr, input unchanged.
- Missing/unreadable input → exit 2.
