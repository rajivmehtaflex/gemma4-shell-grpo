# S09 fixtures · v1

Authored defective starter (delivered as `solution.sh`; authored by the project, not an earlier
Pi mistake):

```bash
#!/bin/bash
pattern="$1"
file="$2"
grep "$pattern" "$file"
```

Demonstrable starter defects: regex metacharacters interpreted (`.` matches any char, `*` as
repetition, `[` can error or mis-match); a term starting with `-` is parsed as a grep option
(grep: unrecognized/unexpected option or silent line-number behavior); an empty term matches every
line instead of being rejected; a missing file does exit 2 but with uncontrolled messaging; there
is no explicit 0/1/2 discipline.
