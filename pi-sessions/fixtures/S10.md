# S10 fixtures · v1

Authored defective starter (delivered as `solution.sh`; authored by the project, not an earlier
Pi mistake):

```bash
#!/bin/bash
count=$(grep "ERROR" "$1" | wc -l)
echo "$count"
```

Demonstrable starter defect: the pipe to `wc -l` swallows `grep`'s failure — a missing or
unreadable input prints `0` and exits 0 (false zero). Counting behavior on readable files is
correct and must be preserved (S06's contract).

## Fixtures

Reuse **S06's fixtures exactly** (F-S06-main, F-S06-none, F-S06-empty, F-S06-tricky, F-S06-missing,
F-S06-unreadable, F-S06-noargs) with S06's expected outputs, plus the starter-defect emphasis:

- **F-S06-missing** — starter prints `0` and exits 0; the repaired script must exit 2 with empty
  stdout and nonempty stderr. This fixture is the reason the task exists.
- **F-S06-unreadable** — same expectation.

Counting fixtures use the same byte contents as S06 so results are directly comparable across the
template family.

Input hash before/after identical in every case.
