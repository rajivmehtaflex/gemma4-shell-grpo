# S08 fixtures · v1

Authored defective starter (delivered to the workspace as `solution.sh`; authored by the project,
not an earlier Pi mistake — record as `authored starter` in provenance):

```bash
#!/bin/bash
for f in $1/*; do
    cp $f "$2"
done
```

Demonstrable starter defects: unquoted `$1`/`$f` (word splitting on spaces, option injection on
leading dashes), glob `*` skips dotfiles, no symlink skip, no destination validation, no exit
status discipline. The repaired script must fix these without changing the two-argument interface.

## F-S08-main

```
src/
  plain.txt                 (regular)
  "my file.txt"             (regular, space)
  -dash.txt                 (regular, leading dash)
  "tab\tname.txt"           (regular, tab in name)
  .hidden                   (regular dotfile — must be copied)
  .cfg                      (regular dotfile)
  link-to-plain.txt         (symlink — must NOT be copied)
  sub/                      (directory — must NOT be copied, contents neither)
    inner.txt
dst/                        (exists, empty)
```

Expected: `dst` contains byte-identical copies of the six regular files (including `.hidden`,
`.cfg`) with their basenames; no symlink; no `sub/`. `src` byte-identical afterwards.

## F-S08-empty-src

`src/` empty; `dst/` empty → success, `dst` stays empty, exit 0.
