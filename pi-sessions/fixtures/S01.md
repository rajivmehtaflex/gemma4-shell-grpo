# S01 fixtures · v1

All fixtures are generated fresh per candidate under a temp root; the grader knows the expected
count independently of the script.

## F-S01-main (expect `5`)

```
root/
  a.txt                 (regular, 3 bytes)
  my report.txt         (regular, name contains space)
  -leading-dash.txt     (regular, name starts with "-")
  "tab\tname.txt"       (regular, name contains a tab)
  "line1\nline2.txt"    (regular, name contains a newline)
  nested/               (directory)
    deep.txt            (regular — must NOT be counted)
  notes.md              (regular — not .txt)
  report.TXT            (regular — case must not match)
  link-to-a.txt         (symlink → a.txt — must NOT be counted)
  plain-file            (regular, no extension)
```

Expected stdout: `5\n`.

## F-S01-empty (expect `0`)

`root/` exists, completely empty. Expected stdout: `0\n`, exit 0.

## F-S01-edge (expect `0`)

`root/` contains only: `nested/x.txt`, `symlink.txt` (symlink → missing target), `b.txt.bak`.
Expected stdout: `0\n`.

## Error fixtures

- **F-S01-noarg** — invoke with no arguments → exit 2, empty stdout, nonempty stderr.
- **F-S01-notdir** — first argument is a regular file → exit 2.
- **F-S01-unreadable** — first argument is a directory with mode `000` (grader runs as
  unprivileged user) → exit 2.

## Side-effects check

Full tree walk (names + bytes + types) hashed before and after; must be identical.
