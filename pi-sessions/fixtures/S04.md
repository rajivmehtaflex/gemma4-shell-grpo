# S04 fixtures · v1

Expected output is NUL-delimited; sortedness is checked on the raw output bytes (entries in C
byte order, each entry NUL-terminated, no `./` prefix).

## F-S04-main

```
root/
  data.csv                              → entry: data.csv
  "my table.csv"                        → entry: my table.csv
  -dash.csv                             → entry: -dash.csv
  "multi\nline.csv"                     → entry: multi\nline.csv (contains a newline)
  a/b/c/deep.csv                        → entry: a/b/c/deep.csv
  a/zz.csv                              → entry: a/zz.csv
  a.csv/a.csv                           → entry: a.csv/a.csv     (directory named like a csv)
  export.CSV                            (excluded — case)
  link.csv                              (symlink → data.csv — excluded, not followed)
  link-dir/                             (symlink → a — excluded, not followed)
  read.me                               (excluded)
```

Byte-order sort key: `-` is 0x2D, `.` is 0x2E, `/` is 0x2F. So `a.csv/...` sorts before `a/...`
(0x2E < 0x2F), and among the `a/` entries, `a/b/...` precedes `a/zz.csv` ('b' 0x62 < 'z' 0x7A).

Expected entries, byte-sorted, in exact output order:

1. `-dash.csv`
2. `a.csv/a.csv`
3. `a/b/c/deep.csv`
4. `a/zz.csv`
5. `data.csv`
6. `multi\nline.csv`
7. `my table.csv`

## F-S04-empty

`root/` empty → empty stdout, exit 0.

## Error fixtures

- **F-S04-noarg** — no arguments → exit 2, empty stdout, nonempty stderr.
- **F-S04-notdir** — argument is a regular file → exit 2.
- **F-S04-unreadable** — directory mode `000` → exit 2.
