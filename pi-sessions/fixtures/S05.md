# S05 fixtures · v1

## F-S05-main (expect exact byte output)

Input (literal tab between fields):

```
apple	3
banana	12
apple	9
Cherry	1
zebra	0
apple	1000000
```

Expected stdout (C byte order of keys: `Cherry` 0x43 < `apple` 0x61 < `banana` 0x62 < `zebra` 0x7A):

```
Cherry	1
apple	1000012
banana	12
zebra	0
```

Exercises: duplicate keys across non-adjacent rows, case-sensitive keys (`Cherry` ≠ `apple`),
large-value sum (1,000,000 boundary), zero value.

## F-S05-single

One row `only	41` → output `only	41`.

## F-S05-empty

Zero-byte file → empty stdout, exit 0.

## Malformed fixtures (each: exit 2, **empty stdout**, nonempty stderr, input unchanged)

- **F-S05-three-fields** — a row with three tab-separated fields.
- **F-S05-empty-key** — a row starting with a tab (`	5`).
- **F-S05-negative** — value `-5`.
- **F-S05-alpha** — value `12a`.
- **F-S05-plus** — value `+7` (not a plain nonnegative integer).
- **F-S05-float** — value `3.5`.

Note: `0012` is a valid plain nonnegative integer (equals 12) — include one such row in a
success-path variant (F-S05-leading-zeros: `k1	0012`, `k1	8` → `k1	20`).

## Error fixtures

- **F-S05-missing** — input does not exist → exit 2, empty stdout.
- **F-S05-unreadable** — mode `000` → exit 2.
- **F-S05-noargs** — no arguments → exit 2.

Input hash before/after identical in every case.
