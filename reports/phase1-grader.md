## Known refinements (non-blocking, recorded for later phases)

1. `invalid_script` currently requires the whole task to restart grading in later runs
   (per protocol it contributes zero per fixture; the task-level pre-check makes all
   fixtures zero — consistent, but a per-fixture syntax check could preserve partial
   scoring for multi-fixture tasks).
2. Daemon-error detection uses exit-code 125 / inspect-failure heuristics; adequate for
   CPU diagnostics, to be re-validated on the Colab host in Phase 2 (the grading contract
   is re-proved per host before any model work, per PLAN).
3. Fixture instances build under the runner work root on tmpfs-backed `/tmp`; large
   fixture sets may need a configured work root on persistent storage.
